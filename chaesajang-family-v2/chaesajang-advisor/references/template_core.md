# template_core.md — 채사장 스타일 글쓰기 예시 (계열 공통)

이 파일은 공식이 아니다. 좋은 예시와 그것이 작동하는 이유다.
예시를 복사하지 말고, 왜 작동하는지를 파악해서 주제에 맞게 판단한다.

---

## 도입: 어떻게 시작할 것인가

채사장의 도입은 독자를 "이미 살고 있는 문제" 앞에 세운다.
핵심 방법이 세 가지, 보조 방법이 세 가지다. 레이블이 아니라 작동 원리를 본다.

원전 실측: 공개 발췌 17개 블록 중 **첫 문장이 물음표인 경우는 0개**였다.
질문은 도입의 형식이 아니라 논증을 움직이는 장치다. 도입에서 질문은 '소환'할 뿐이다.

---

### 질문형 도입

독자가 이미 하고 있는 행위 안에 숨어 있는 질문을 꺼낸다.
질문이 독자 자신의 것이어야 작동한다.
"세금이란 무엇인가"는 세금을 내는 사람의 질문이다.
"헤겔의 변증법이란 무엇인가"는 아직 독자의 질문이 아니다.
물음표로 시작하는 게 아니라, 평서문 안에 질문을 소환한다.

```
우리는 매달 세금을 낸다.
그런데 '세금이 무엇인가'라는 질문에 제대로 답할 수 있는 사람은 많지 않다.
```

```
살면서 한 번쯤 '내 노력이 왜 결과로 이어지지 않을까'를 생각해본 적 있을 것이다.
이 질문은 보통 자신을 향한다.
그런데 방향을 바꿔보면 어떨까.
```

```
역사는 반복된다.
이 말이 위안인지 경고인지는, 역사를 어떻게 읽느냐에 달려 있다.
```

세 예시의 구조는 다르다. 공통점은 하나다. 독자를 질문 앞에 세운다.

---

### 역설형 도입

독자가 당연하게 여기는 통념을 먼저 인정한 뒤 뒤집는다.
반전이 강할수록 좋다. 단, 뒤집을 통념이 독자 대부분이 실제로 믿는 것이어야 한다.

```
우리는 민주주의가 다수결이라고 배웠다.
그런데 다수결은 민주주의의 여러 요소 중 하나일 뿐이다.
이 차이가 작아 보이지만, 여기서 민주주의 이해가 완전히 달라진다.
```

```
과학은 진리를 발견한다고 우리는 배웠다.
그런데 과학자들은 진리를 발견하는 것이 아니라, 더 나은 설명을 선택하는 것이라고 말한다.
```

---

### 장면 도입 (역사적 장면 또는 우화·비유)

구체적인 장면으로 바로 시작한다. 역사적 사건일 수도 있고, 강렬한 우화나 비유일 수도 있다.
첫 문장이 평서문이어도 괜찮다. 장면 자체가 진입점이다.
현재와 연결된다는 암시를 마지막에 둔다. 연결을 직접 설명하지 않는다.

**역사적 장면**:
```
1929년, 뉴욕 월스트리트에서 주가가 폭락했다.
단 며칠 만에 수백만 명의 삶이 무너졌다.
이 사건은 경제 위기가 아니었다. 세계가 작동하는 방식에 대한 질문이었다.
```

```
1517년, 마르틴 루터는 교회 문에 95개의 반박문을 붙였다.
그는 교회를 무너뜨리려 한 것이 아니었다.
그러나 그 행동이 유럽을 반으로 갈랐다.
```

**우화·비유적 장면** (역사 장면보다 심리적 충격이 클 때 선택한다):
```
관광객을 등에 태우기 위해 아기 코끼리는 매를 맞는다.
자아가 완전히 꺾일 때까지.
그 이후 코끼리는 더 이상 도망치려 하지 않는다.
우리는 이것을 순응이라고 부른다.
```

우화를 쓸 때의 조건: 우화가 개념을 직접 이미지화해야 한다. 분위기만 만드는 우화는 장식이다.
이 방식이 질문형보다 강한 진입점일 때 선택한다.

---

### 보조 도입: 인용·문학 인트로형

다른 작품의 문장(특히 첫 문장)이나 고전 명문을 전면에 내세운 뒤, 그 문장을 발판 삼아 자기 글을 전개한다. 장면형에 가깝지만, "타자의 문장 위에 자기 글을 얹는" 방식이 구별점이다.

채사장은 『우리는 언젠가 만난다』에서 가와바타 야스나리 『설국』의 첫 문장을 인용해 도입하고, 『열한 계단』에서 도스토옙스키·니체·붓다의 고전 텍스트를 각 챕터 앞에 놓는다.

핵심 방법이 아닌 보조 수단이다. 주제와 직결되는 고전 문장이 있을 때만 선택한다.

---

### 보조 도입: 선언·정의형

질문이나 장면 없이, 곧바로 핵심 정의나 명제를 제시한다.

```
정의란 '같은 것을 같게', '다른 것을 다르게' 대우하는 것이다.
```

정치·윤리·교양 개념을 다루는 장에서 빈번하다. 질문형이나 장면형으로 우회할 여유가 없을 때, 또는 개념 자체가 충분히 강렬할 때 선택한다.

---

### 보조 도입: 개인 관찰형

**작동 원리**:
보편적인 개인 경험에서 출발해 철학적·사회적 구조로 확장한다.
독자가 "나도 그런 적 있다"고 느끼는 경험이어야 한다.

**적용 조건**: 개인 경험에서 사회 구조 또는 철학적 함의로 확장할 때.

**예시**:
```
살면서 한 번쯤은 내가 왜 이렇게 사는 걸까, 라는 생각을 해봤을 것이다.
이 질문을 불안의 증거라고 보는 사람도 있다.
철학자들은 이를 인간이 인간임을 증명하는 순간이라고 말한다.
```

## 개념 설명: 추상에서 구체로

기본 방향은 추상 → 구체 → 비유 → 한 문장 정리다.
비유는 개념을 더 명확하게 만들 때만 추가한다. 비유가 목적이 아니다.

```
잉여 가치란 노동자가 만들어낸 가치 중 임금으로 돌아오지 않는 부분이다.
하루에 100만 원어치 제품을 만드는 노동자가 30만 원을 받는다면,
나머지 70만 원은 자본가에게 귀속된다.
마르크스는 이 구조가 자본주의의 우연한 결함이 아니라 작동 원리 자체라고 봤다.
쉽게 말하면, 내가 일한 시간 중 나를 위한 시간과 타인을 위한 시간의 차이다.
결국 잉여 가치는 자본주의가 유지되는 연료다.
```

독자가 이미 개념을 어느 정도 알고 있다면, 아는 설명을 먼저 인정하고 더 깊이 들어간다.

```
자유란 하고 싶은 것을 할 수 있는 상태라고 흔히 말한다.
사실 이것은 자유의 절반만 담은 설명이다.
더 정확하게 말하면, 자유는 하기 싫은 것을 거부할 수 있는 상태다.
이 차이는 우리가 어떤 사회 제도를 설계하느냐에서 결정적으로 드러난다.
```

---

### 개념 설명 변형: 점층적 심화

**작동 원리**:
독자가 이미 아는 설명을 먼저 인정하고, 그것이 불완전하다는 것을 보여준다.
"사실은 더 정확하게 말하면"의 구조로 깊이를 더한다.

**적용 조건**: 독자가 개념을 이미 어느 정도 알고 있을 때.

**흐름**:
```
[개념]은 [독자가 아는 설명]이라고 흔히 말한다.
사실 이것은 [개념]의 절반만 담은 설명이다.
더 정확하게 말하면, [더 깊은 설명]이다.
이 차이는 [실제 결과]에서 드러난다.
```

**예시**:
```
자유란 하고 싶은 것을 할 수 있는 상태라고 흔히 말한다.
사실 이것은 자유의 절반만 담은 설명이다.
더 정확하게 말하면, 자유는 하기 싫은 것을 거부할 수 있는 상태다.
이 차이는 우리가 어떤 사회 제도를 설계하느냐에서 결정적으로 드러난다.
```

---

### 개념 설명 변형: 비교·대조

**작동 원리**:
두 개념을 나란히 놓아 차이를 드러낸다.
표면적 유사점을 먼저 인정하고, 결정적 차이로 이동한다.

**흐름**:
```
[A]는 [핵심 특징]이다.
[B]는 [핵심 특징]이다.
표면적으로 둘은 비슷해 보인다.
그런데 결정적인 차이는 [차이점]이다.
이 차이가 [실제 결과]를 만든다.
```

## 전개: 예상치 못한 연결

하나의 개념을 설명한 뒤, 전혀 다른 분야와의 연결로 독자가 예상하지 못한 시야를 만든다.
연결은 억지로 만들지 않는다. 실제로 구조가 같을 때만 연결한다.

```
마르크스는 경제가 역사를 만든다고 했다.
다윈은 환경이 생명을 만든다고 했다.
프로이트는 무의식이 인간을 만든다고 했다.
셋 다 같은 말을 하고 있다. 우리가 의식하지 못하는 무언가가 우리를 움직인다는 것이다.
```

같은 구조의 문장을 반복할 때, 반복 횟수는 리듬이 완성된다고 느껴지는 지점에서 결정한다.
2회로 충분하다면 굳이 3회를 채우지 않는다.

---

### 전개 변형: 논증 중간의 질문 연쇄

원전에서 질문은 도입이 아니라 **전개의 점프대**로 쓰인다.
정의나 장면을 제시한 뒤, 짧은 질문을 연달아 던져 독자를 한 단계씩 옮긴다.
물음표 형태("~인가", "~는가")도, 물음표 없는 의문형("~일까", "~는지")도 쓰인다.
원전 실측: 수사 의문 마커(인가 5~9/10k, 는가 4.5~7/10k)가 양서에서 꾸준히 관측됐다.

```
국가는 어디서 왔는가. 왜 사람들은 스스로에게 규칙을 묶어 두었는가.
안전 때문일까. 그렇다면 왜 그 규칙은 안전과 무관한 곳까지 손을 뻗는가.
```

판단 기준:
- 질문 연쇄는 2~3개가 한 묶음이다 (원전 관측값)
- 답을 아는 질문(수사 의문)과 진짜 열린 질문을 섞는다
- 한 단락 전체를 질문으로만 채우지 않는다

---

### 전개 변형: 반복 강조형

**작동 원리**:
같은 구조의 문장을 반복해 패턴을 각인시키고, 정리 문장으로 수렴한다.
반복 횟수는 리듬이 완성된다고 느껴지는 지점에서 결정한다. 보통 2~4회.
한 편에서 이 장치는 최대 1회다. 연속하는 글에서 같은 마무리 장치를 재사용하지 않는다.

**흐름**:
```
[사례 A]는 [공통 구조]였다.
[사례 B]는 [공통 구조]였다.
[사례 C]는 [공통 구조]였다.
[패턴을 한 문장으로 정리]
```

**주의**: 반복은 독자가 리듬을 느끼기 위한 것이다.
억지로 3개를 맞추는 것보다 2개가 더 강렬할 수 있다. 숫자보다 리듬을 본다.

## 통찰: 어떻게 마무리할 것인가

마무리의 방향은 네 가지다.

**도입으로 귀환**: 처음 질문을 다시 꺼내, 본문에서 쌓은 맥락으로 다른 답을 제시한다.
```
처음 질문으로 돌아가보자. 세금이란 무엇인가.
이제 이 질문은 납세의 의무에 관한 것이 아니다.
우리가 어떤 사회에서 살고 싶은가에 관한 질문이다.
```

**인식의 역전**: 독자가 갖고 있던 인식을 명시적으로 뒤집는다.
```
우리는 경제를 숫자의 학문이라고 생각해왔다.
그런데 경제는 인간의 욕망과 공포가 만들어내는 이야기다.
```

**확장 후 착지**: 개인 → 사회 → 역사로 넓혔다가, 마지막 문장을 독자의 현재로 돌린다.

**판단의 위임**: 두 세계의 구조와 논리를 공정하게 펼친 뒤, 결론을 비운다. 작가가 판단을 독점하지 않는다.
```
보수의 세계와 진보의 세계, 두 가지를 살펴봤다.
어느 쪽이 옳은가는 이 글이 답할 수 있는 질문이 아니다.
어떤 가치를 더 중요하게 여기는가 — 그것은 당신이 결정할 일이다.
```

이 방식이 작동하는 조건: 두 입장이 구조적으로 공정하게 제시됐을 때만 결론을 위임할 수 있다. 한쪽만 충분히 설명한 상태에서 판단을 넘기면 위임이 아니라 회피가 된다. 또한 "어느 쪽이 맞는지 모르겠다"는 결론 회피(anti_patterns.md 참고)와 구별해야 한다 — 판단의 위임은 구조적 차이를 드러낸 뒤 선택을 넘기는 것이다.

넷 중 무엇을 고르든, 글쓴이가 통찰을 선언하지 않는다.
독자가 스스로 도달한 것처럼 느껴야 한다.
마무리 유형은 한 편에 하나다. 연속하는 글에서 같은 유형·같은 형태('결국 X란 Y다' 압축 등)를
반복하면 기교 과적이 된다 → `reference_core.md`의 기교 예산 참고.

### 보조 결론: 정리·공식형

"정리해보자", "정리하면", "결론적으로 말해"로 시작해, 핵심 개념들을 대비·공식처럼 나열하는 방식. 위 네 유형과 동시에 결합되며, 특히 교양서에서 챕터 말미에 빈번하다.

```
정리해보자.
보수는 세금과 복지를 줄여 경쟁력을 우선하고,
진보는 세금과 복지를 늘려 삶의 질을 우선한다.
```

이 패턴은 "이 글에서는 ~을 다루겠다"류의 사전 안내(메타 설명)와 다르다. 사전 안내는 글이 시작되기 전에 길의 끝을 보여주는 것이고, 정리·공식형은 본문에서 쌓은 것을 한 줄로 압축하는 것이다.

### 보조 결론: 역전형

**작동 원리**:
독자가 갖고 있던 인식을 명시적으로 뒤집는다.
"우리는 X라고 생각해왔다. 그런데 실제로는 Y다."

**예시**:
```
우리는 경제를 숫자의 학문이라고 생각해왔다.
그런데 경제는 인간의 욕망과 공포가 만들어내는 이야기다.
이것은 경제학의 이야기가 아니다.
우리가 왜 지금 이런 선택을 하는지를 이해하는 출발점이다.
```

---

### 보조 결론: 확장형

**작동 원리**:
개인 수준의 현상을 사회 구조, 역사 맥락으로 넓혀간다.
마지막 문장은 독자의 현재 현실로 돌아온다.

**흐름**:
```
이것은 개인의 문제가 아니다.
[사회 구조 차원 설명]
더 크게 보면, [역사·철학적 맥락]
결국 우리가 [경험]을 겪는 것은 [구조적 이유] 때문이다.
```

---

### 보조 결론: 열린 질문형

**작동 원리**:
마무리를 선언이나 정리가 아닌 의문문으로 닫는다.
닫히지 않은 질문은 독자의 내면으로 이전된다.
독자가 "나도 그렇다"고 스스로 느끼게 만드는 것이 목표다 — 글쓴이가 선언하면 안 된다.
이 형식은 개인적 통찰이나 존재론적 질문으로 귀결되는 글에 가장 유효하다.

**흐름**:
```
[글쓴이 자신의 경험이나 인식 변화를 1인칭으로 서술]
[그 경험이 가리키는 더 넓은 조건 또는 구조를 한 문장으로]
혹시 [독자 자신을 향한 의문문]?
```

**예시 A** (자기 인식):
```
나는 오랫동안 그 문제를 바깥에서 찾았다.
그런데 구조를 이해하고 나니, 내가 그 구조의 일부였다는 것이 보였다.
눈을 뜨고 있어도 보지 못하는 사람이 있다.
혹시 내가 그런 사람은 아니었을까.
```

**예시 B** (관계):
```
우리는 타인을 이해한다고 생각한다.
그런데 이해는 대개 자신의 언어로 상대를 번역한 것에 가깝다.
혹시 우리가 나눈 대화 중 진짜 상대의 말을 들은 순간이 얼마나 됐을까.
```

**판단 기준**:
- 의문문은 하나여야 한다. 두 개 이상이면 질문이 흩어진다.
- 독자를 향한 질문이어야 한다. 세계를 향한 질문은 다른 패턴이다.
- 이 형식을 남발하면 글이 항상 불안하게 끝난다는 인상을 준다.
  확실한 구조적 결론이 있을 때는 T-INSIGHT-A나 B를 쓴다.
### 도입–결론 짝 패턴

실제 텍스트에서 관찰되는 대응 관계. 규칙이 아니라 경향이다. 도입 유형을 선택하면 먼저 검토할 결론 유형의 참고선으로 쓴다.

- 장면형 도입 → 확장 후 착지형 결론: 낯선 장면에서 시작해 구조를 넓힌 뒤 독자의 현재로 돌아온다.
- 질문형 도입 → 판단 위임형 결론: 선택지를 던져 시작하고, 구조를 분석한 뒤 독자에게 선택을 돌린다.
- 역설형 도입 → 인식 역전형 결론: 통념을 뒤집어 시작하고, 마지막에 가치 판단을 정반대로 재배치한다.

## 종합 예시

**주제: 습관이란 무엇인가**

사용 패턴: T-장면형(일상) → 개념 설명(용어 지연 도입) → 논증 중간 질문 연쇄 → 확장 후 착지

```
아침에 눈을 뜨면 손이 먼저 움직인다. 휴대폰을 향해. 생각보다 빠르게.
그 손은 오늘 처음 그런 게 아니다. 지난 몇 년간 매일 그래왔다.

행동이 반복되면 뇌는 그것을 목록에 저장한다. 매번 새로 결정하는 게 아니라
저장된 프로그램을 실행하는 것. 이를 어려운 말로 '습관화'라고 부른다.
신호가 오면 행동이 따라오고, 결과가 좋으면 회로가 굳는다.

그런데 여기서 이상한 질문 하나가 나온다. 그 손을 움직인 것은 나인가, 회로인가.
의지는 매번 새로 소모된다. 회로는 한 번 굳으면 저절로 돈다.
이길 수 없는 싸움이라면, 이기려 하지 말고 다른 질문을 해야 한다.

회로를 만드는 입력은 무엇이었나. 침대 머리맡에 둔 휴대폰. 현관에 없던 운동화.
습관의 설계도는 다짐이 아니라 배치에 적혀 있다.
오늘 아침 손이 뻗어간 그 거리를 조금 옮겨두는 것부터가 설계의 시작이다.
```

→ 예시는 소재 복사용이 아니다. 패턴의 작동을 보여주기 위한 것으로,
세금·민주주의 등 기존 예시 소재를 그대로 가져오면 흉내가 된다.
