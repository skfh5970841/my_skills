# reference_core.md — 채사장 스타일 문장 패턴 (계열 공통)

각 패턴은 규칙이 아니라 채사장이 자주 선택하는 방식이다.
패턴을 기계적으로 적용하지 말고, 이 패턴이 왜 작동하는지를 파악해 판단에 활용한다.
빈도 정보는 책 2권(『지대넓얕 1』『시민의 교양』) 전문 약 7,400문장의 실측값이다.

---

## 문장 리듬 — 세 박자

원전의 기본 박자는 다음과 같다.

> **짧게 전제한다 → 길게 확장한다 → 짧게 판정한다.**

원전의 중위값은 문장당 30자 안팎이고, 60자 이상의 확장문도 11~14%를 차지한다.
긴 문장 하나가 개념을 펼치면, 그 직후의 짧은 문장이 그것을 묶는다.
긴장과 이완은 개수가 아니라 대비에서 나온다.

실행 앵커:
- **단락 하나에 40자를 넘는 확장 문장이 최소 하나 있다.** 없으면 개념이 펼쳐지지 않은 것이다.
- 평균이 25자 밑으로 내려가면 과단편화 신호다. 다음 단락에서 확장 문장으로 되돌린다.

### P-RHYTHM-A: 단문 연속 → 장문 전환

**작동 원리**:
짧은 문장들로 독자의 호흡을 빠르게 만든 뒤, 긴 문장으로 개념을 펼친다.
그 직후의 짧은 문장이 그것을 묶는다. 단문만 계속하면 리듬이 단조로워진다 — 확장문은 피할 것이 아니다.

**예시 A**:
```
역사는 반복된다. 아니, 정확히 말하면 구조가 반복된다.
사람은 바뀌고, 시대는 바뀌고, 이름도 바뀌지만,
그 안에서 작동하는 힘의 방향은 놀랍도록 일정하다.
```

**예시 B**:
```
돈은 종이다. 그 이상도 이하도 아니다.
그런데 그 종이 한 장이 누군가의 하루를 바꾸고, 누군가의 인생을 끝내기도 한다.
우리가 돈에 부여한 의미가 돈 자체보다 훨씬 강력하기 때문이다.
```

**예시 C**:
```
자유는 좋은 것이다. 누구나 원한다.
문제는 자유가 하나가 아니라는 것이다.
어떤 자유는 다른 사람의 자유를 빼앗는 방식으로만 실현된다.
```

---

### P-RHYTHM-B: 반복 → 수렴

**작동 원리**:
같은 구조의 문장을 반복하면 독자는 리듬을 느끼고 패턴을 예상한다.
그 예상이 충족될 때 정리 문장이 힘을 얻는다.
반복 횟수는 숫자로 정하지 않는다. 리듬이 완성되면 멈춘다.
한 편에서 이 장치는 최대 1회다. 매 글에서 쓰면 버릇이 된다.

**예시 A** (3회):
```
봉건제는 토지가 권력이었던 시대다.
자본주의는 돈이 권력인 시대다.
지금 우리가 사는 시대는 정보가 권력이 되어가는 시대다.
무엇이 권력인지가 바뀌면, 세상이 바뀐다.
```

**예시 B** (3회):
```
마르크스는 경제가 역사를 만든다고 했다.
다윈은 환경이 생명을 만든다고 했다.
프로이트는 무의식이 인간을 만든다고 했다.
셋 다 같은 말을 하고 있다. 우리가 의식하지 못하는 무언가가 우리를 움직인다는 것이다.
```

**예시 C** (2회로 충분한 경우):
```
어떤 사람은 열심히 하면 된다고 말한다.
어떤 사람은 좋은 환경이 필요하다고 말한다.
두 주장 모두 맞다. 그리고 두 주장 모두 절반만 맞다.
```

→ 예시 C는 2회 반복만으로 수렴했다. 리듬이 완성됐으면 굳이 3회를 채우지 않는다.

---

### P-RHYTHM-C: 역접 배치

**작동 원리**:
역접은 논리의 방향이 실제로 꺾일 때만 넣는다.
원전에서 주력 역접어는 **하지만 / 다만 / 그러나**다. "그런데"는 중빈도 보조 수준이다.
역접을 단독으로 떼어 놓으면("그런데.") 무게가 커지지만, 이것은 특수한 강조 장치다.
한 편에 한 번 이상 쓰지 않는다.

**예시 A** (평형형):
```
경쟁은 사람을 성장시킨다. 대부분이 그렇게 믿는다.
하지만 경쟁의 보상이 제대로 작동하려면, 지지 않아도 먹고살 수 있는 바닥이 필요하다.
그 바닥이 없는 곳에서 경쟁은 성장이 아니라 선별이 된다.
```

**예시 B** (단독 배치 — 특수 장치):
```
민주주의는 다수의 지혜를 믿는 제도다. 논리적으로 완벽해 보인다.
그런데.
다수가 소크라테스를 죽였을 때, 그 믿음은 이미 금이 간 것이었다.
```

## 구조 패턴

### P-STRUCTURE-A: 나선형 확장

개인 경험 → 사회 현상 → 역사 맥락 → 철학적 질문 → 독자 현재로 귀환.
동심원을 그리듯 넓혀가고, 반드시 독자의 현재로 돌아온다.

**적용 예시**:
```
"왜 이렇게 불안할까" (개인)
→ 현대인의 불안은 개인 문제가 아니다 (사회)
→ 산업화 이후 공동체가 해체되면서 시작됐다 (역사)
→ 실존주의는 이를 '던져진 존재의 조건'이라 불렀다 (철학)
→ 그렇다면 이 불안을 어떻게 대할 것인가 (독자 귀환)
```

---

### P-STRUCTURE-B: 이중 반전

통념을 한 번 뒤집고, 그 뒤집은 것도 다시 뒤집어 더 깊은 이해에 도달한다.

```
[통념 A]
→ [반전 1: 사실은 B다]
→ [반전 2: 더 정확하게는 A와 B를 포함한 C다]
```

**적용 예시**:
```
역사는 승자의 기록이다. (통념)
→ 그래서 역사는 편향돼 있고 믿기 어렵다. (반전 1)
→ 그런데 그 편향 자체를 읽는 것이 역사를 이해하는 방법이다. (반전 2)
```

---

### P-STRUCTURE-C: A/B 인물화

**작동 원리**:
추상적 사회 구조(권력, 계급, 이데올로기)를 이름 없는 두 인물 A와 B의 구어체 대화로 치환한다.
독자는 개념을 이해하는 것이 아니라 장면을 목격한다. 이해는 그 뒤에 따라온다.
핵심은 세 가지다: (a) A/B에는 실명이 없다 — 보편 구조를 나타내기 위함, (b) 대화는 반드시 현대 구어체로 쓴다 — 시대를 초월한 친밀감 생성, (c) 대화 직후 1문장으로 구조 해석을 박는다.

**흐름**:
```
[A와 B의 구어체 대화 — 시대착오적 유머 포함 가능]
[구조 해석 1문장: "~가 발생했다" 또는 "이것이 바로 ~이다"]
[개념의 정식 명칭은 이 이후에 등장한다]
```

**예시 A** (권력 발생):
```
"곡식 좀 같이 먹지." "먹어 주지. 그런데 창고 청소는 네가 하게."
지시 관계가 발생했다.
저장한 쪽이 관계의 방향을 결정한다 — 이것이 계급의 기원이다.
```

**실측 보강**: 지대넓얕 1에서 문장 열두 개 중 하나(12.7%)가 인용부호 안에 있을 정도로,
이 장치는 스타일의 핵심 부분이다. 단, 한 편에서 최대 1회. 모든 글의 의무 장치가 아니다.

**판단 기준**:
- 이 패턴은 계급·권력·이데올로기처럼 구조적 관계를 설명할 때 유효하다.
- 단순 사실이나 자연현상 설명에는 불필요하다.
- 대화가 너무 길어지면 장면이 아니라 소설이 된다. 3~5줄이 한계다.

## 어휘 및 비유 판단 기준

### 서술어 선택 원칙

피해야 할 것은 특정 서술어가 아니라,
**글쓴이의 감정·판단이 독자 위에 군림하는 구조**다.

| 구조 | 판단 | 이유 |
|---|---|---|
| "나는 이것이 중요하다고 생각한다" | 피한다 | 글쓴이 판단을 강요한다 |
| "이것이 중요한 이유는 ~이기 때문이다" | 권장 | 구조로 설명한다 |
| "당신은 아마 이렇게 생각할 것이다" | 허용 | 독자 시점을 대변한다 |
| "~인 셈이다 / ~라고 할 수 있다" | 권장 | 중립적 서술, 독자 판단 여지를 남긴다 |

### 전문 용어 지연 도입

전통적 설명은 용어를 먼저 제시하고 설명한다. 채사장은 역순이다.
개념을 먼저 완전히 이해시킨 뒤, 용어를 나중에 붙인다.
이 순서의 역전이 독자의 위축감을 제거한다.

**순서**:
```
[현상을 일상어로 묘사]
→ [재진술 또는 구체화]
→ "이를 어려운 말로 '~'라고 한다"
→ [구어체 감정 표현 또는 가벼운 언급으로 학술적 무게 즉시 해소]
```

**예시 A**:
```
수요는 없는데 물가는 오르는 상황.
경기는 침체하는데 인플레이션이 발생한 것이다.
이를 어려운 말로 '스태그플레이션'이라고 한다.
이런 상황이 실제로 일어날 수 있다는 게 꽤 당혹스럽다.
```

**예시 B**:
```
공장이 생기고, 기계가 생기면서 예전보다 훨씬 많은 물건을 만들 수 있게 됐다.
그런데 이 물건들을 만들어낸 기계와 공장을 소유한 사람은 따로 있었다.
그 소유자들을 '부르주아'라고 부른다.
지금 우리가 말하는 중산층이나 사업가와는 결이 조금 다르다.
```

**금지**: 용어를 먼저 정의하고 사례를 나중에 붙이는 순서.
독자는 용어와 함께 길을 잃기 시작한다.

### 비유 판단 기준

비유는 개념을 더 명확하게 만들 때만 쓴다.
서정적이냐 아니냐가 기준이 아니라, **기능하느냐 아니냐**가 기준이다.

- 비유를 읽은 독자가 개념을 더 잘 이해하는가 → 쓴다
- 비유 자체는 아름답지만 개념과 따로 노는가 → 버린다
- 비유를 지웠을 때 감정적 충격이 사라지고, 그 충격이 개념 각인의 핵심인 경우 → 기능하는 비유다

**기능하는 비유 예시**:
```
"규칙을 만드는 사람과 규칙 안에서 노는 사람"
→ 권력의 층위를 명확히 이미지화한다.

"빙산의 수면 아래처럼"
→ 보이지 않는 구조가 있다는 것을 즉시 시각화한다.
```

**기능하지 않는 비유 예시**:
```
"강물처럼 흘러가는 시간"
→ 시간이 흐른다는 것 외에 아무것도 추가하지 않는다.

"마치 첫사랑처럼 설레는 지식"
→ 지식의 속성을 설명하지 않는다. 감성만 추가한다.
```

### 전환어 — 목록이 아니라 방향

원전 실측 빈도 (1천 글자당, 책 2권):

| 전환어 | 빈도 | 용도 |
|---|---|---|
| 그리고 | 7.5~10.6 | 나열·순서 이동 |
| 하지만 | 7.9~9.2 | 역접 (주력) |
| 우선 | 4.6~8.7 | 순서 제시 |
| 그래서 | 4.6~5.4 | 귀결 |
| 다음으로 | 2.4~4.1 | 순서 이동 |
| 즉 | 2.6~3.7 | 재정의 |
| 다만 | 2.5~4.6 | 부분 역접·조건 |
| 그런데 | 3.5~3.7 | 화제 전환 (중빈도) |
| 결국 | 2.2~2.7 | 수렴 마무리 |

주의: 이 표를 한 편에서 골고루 소진하려 하지 않는다.
체크리스트처럼 쓰면 글에서 티가 난다. 선택 기준은 빈도가 아니라 **논리의 방향**이다.

- 방향을 되짚으며 반대로 꺾을 때 → 하지만 / 다만 / 그러나
- 나열을 이어붙일 때 → 그리고 / 우선 / 다음으로
- 결과로 내릴 때 → 그래서 / 결국 / 즉
- 정의를 다시 말할 때 → 쉽게 말하면 / 다시 말해

**원전 미관측 표현**: "흥미로운 것은"(0회), "다시 말하면"(0회).
흉내 내려고 넣으면 오히려 흉내로 보인다.

"사실"은 원전에서 명사 용법과 섞여 있어 순수 전환어로서의 빈도는 중간 수준이다.
"사실 ~"로 독자가 놓쳤을 배경을 열어줄 때만 쓴다.

---

### 전환어 없는 전환 패턴

채사장의 리듬은 전환어보다 구조적 전환에서 더 강하게 느껴지는 경우가 많다.
전환어 없이도 단락을 자연스럽게 넘기는 네 가지 패턴이 있다.

**질문으로 닫고 답으로 여는 구조.**
앞 단락 끝을 질문으로 닫고, 다음 단락을 직답으로 시작한다.
전환어 없이도 독자가 질문→답이라는 구조를 따라가기 때문에 전환이 자연스럽다.
```
그렇다면 우리는 어떤 사회를 선택해야 할까.
[다음 단락] 우리가 선택해야 할 사회는 ~이다.
```

**예시 → 개념화 점프.**
한 단락에서 구체적 사례를 전개한 뒤, 다음 단락을 추상 명제로 연다.
사례 단락과 개념 단락의 충돌 자체가 전환 역할을 한다.
```
[사례 단락 전체]
[다음 단락] 이 사례들이 공통적으로 보여주는 것은 ~이다.
```

**시간·시점 점프.**
에세이·자기서사에서 "몇 년 전이었다", "어느 날 문득" 등으로 새 단락을 시작해 접속부사 없이 장면을 전환한다.

**소제목·계단 구조 자체가 전환 장치.**
긴 글에서 소제목이 "여기서부터 다른 층위의 이야기"라는 신호를 대신한다. 그 안에서는 전환어가 없어도 독자가 따라온다.

### 독자를 어디에 세우는가

원전에서 독자를 부르는 방식의 밀도는 명확한 순서가 있다.

**우리(기본 위치) >> 당신(간헐적) > 여러분(거의 안 씀).**

"우리"는 논증 안으로 독자를 끌어들이는 기본 자리지만, 원전 밀도는 문장 몇 개당 한 번 수준이다.
매 단락 "우리는 ~한다"를 반복하면 과잉이다. 독자를 소환하는 것과 잡아두는 것을 구분한다.

---

### 기교 예산 — 시그니처는 아껴 쓴다

채사장의 기교들 — 반복 후 수렴, 역접 단독 배치, '결국 X란 Y다' 압축 마무리,
A/B 인물화 — 는 원전에서도 드물게 등장하기 때문에 강한 것이다.

- 같은 기교를 한 편에서 두 번 이상 쓰지 않는다.
- 연속해서 쓰는 여러 글에서 같은 기교·같은 마무리 형태를 재사용하지 않는다.
- 기교를 하나 뺄 수 있다면 뺀다. 남은 것이 더 눈에 띈다.

기교가 반복되기 시작하면 그것은 스타일이 아니라 버릇이다.

---

### 종결어미 판단 기준

실제 텍스트 분석 기준: "~다/이다" 체가 전체 문장의 80~90% 이상을 차지한다.

**기본값은 `~다/이다` 체다.**

구어체 종결어미(~거지, ~야, ~잖아)는 두 가지 맥락에서만 쓴다.
- 독자의 속마음·반론을 직접 재현할 때: "왜 내가 이런 걸 알아야 하는 거지?"
- 감정이 응축된 결론부·자기고백에서 포인트를 찍을 때: "좋아하는 거지.", "완성되는 거지."

글 유형별 상한:
- 설명서형(지식·역사·사회 개념 중심) → 0~1회
- 에세이·자기서사형(관계·감정·개인 경험 중심) → 2~3회

"편안한 확신"은 종결어미가 아니라 어휘 선택과 문장 방향성에서 만든다.
구어체 어미를 많이 쓴다고 채사장에 가까워지는 것이 아니다.
음성 매체(팟캐스트·강연)의 구어적 말투와 인쇄 텍스트의 문체를 혼동하지 않는다.

## 글 길이별 적용 가이드

채사장의 구조 원칙은 길이에 따라 층수가 달라질 뿐, 기본 골격은 유지된다.
단일 축 수렴은 어떤 길이에서도 포기하지 않는 상수다.

### 짧은 글 (500자 이하: SNS, 브런치 단문, 인터뷰 답변)

축 한 줄 → 대비 1개 → 한 줄 통찰. 3단 구조로 압축한다.
분야 횡단과 다중 계단은 의도적으로 포기한다. 예시는 최대 1개.

점검: "이 글의 축은 한 문장으로 말할 수 있는가?" "마지막 문장은 구조적 결론인가, 감상 나열인가?"

### 중간 길이 (500~2000자: 에세이, 칼럼)

축 1개 + 2~3개 분야 횡단 + 1~2회 나선 루프.
구체적 장면이나 사례로 도입 → 축 위에 올려 단순화 → 인접 분야 2~3개에서 같은 패턴 소개 → 원래 사례로 돌아와 재해석 → 독자의 선택으로 수렴.

계단 수를 욕심내지 않는다. 한 계단만 확실히 오르도록 설계한다.

### 긴 글 (2000자 이상: 책 챕터)

현재 스킬이 전제하는 풀 구조. 나선형 다중 루프, 복수 축, 분야 과다 횡단, 서사 프레임까지 모두 활성화.
각 소단원에서 "도입→횡단→수렴"을 한 번씩 수행하고, 장 전체는 그 소단원들을 다시 감싸는 상위 나선으로 설계한다.

## 비인문 주제에서의 비유 패턴

채사장은 정치·경제·역사 외에 과학·예술·관계·심리 주제에서도 단일 축 구조를 유지한다.
축의 이름만 바뀔 뿐, 글쓰기 구조는 동일하다.

과학·우주: 축은 "진리/절대·상대·회의" 또는 "자아/세계·의식/우주". 과학사 연대기를 따라가다 마지막에 "과학은 진보하지 않는다" 같은 메타 결론으로 회수한다.
예술: 축은 "진리 후보로서의 예술". 회화사의 형식 변화를 따라가며 "인식 구조의 변화"로 읽는다.
관계·심리: 축은 "관계". 개인의 정서 경험(외로움, 연애, 이별)에서 출발해 "세계의 구조 재편", "새 세계와의 조우" 같은 우주적 이미지로 키운다. 인문 주제와 비유 방향이 반대다 — 인문에서는 개인을 구조의 단면으로 축소하고, 관계·심리에서는 개인 경험을 우주적 스케일로 확장한다.

비인문 주제로 글을 쓸 때:
1. 그 주제에서 사용할 단일 축을 하나 고른다.
2. 그 축을 따라 역사·사례·경험을 횡단한다.
3. 마지막에 자아/세계/관계/의식 가운데 하나로 수렴시킨다.

## 종합 적용 예시

**주제: 평등이란 무엇인가**

사용 패턴: T-장면형 도입 → P-STRUCTURE-C(A/B 인물화) → P-RHYTHM-C → 수렴 마무리

```
1789년 파리에서 사람들은 요새를 허물었다. 자유, 평등, 박애. 슬로건은 간결했다.
그런데 그 슬로건 속의 '평등'이 무엇을 뜻하는지는, 두 백 년이 지난 지금도 합의되지 않았다.

A는 월급을 똑같이 나누자고 말한다. B는 출발선만 같게 하자고 말한다.
A가 말하는 건 결과의 평등이고, B가 말하는 건 기회의 평등이다.
두 평등은 친구가 아니다. 하나를 올리려면 하나를 내려놔야 하는 경우가 많다.

하지만 논쟁은 여기서 끝나지 않는다.
기회의 평등을 말하는 사회에서도, 부모의 부가 자녀의 출발선을 앞당겨 놓는다.
출발선이란 처음부터 하나가 아니었다.

결국 평등이란 무엇인가 묻는 일은, 무엇과 무엇을 맞바꿀 것인가 묻는 일이다.
```

→ 이 예시를 복사하지 않는다. 소재와 구조가 아니라 패턴의 작동을 보기 위한 것이다.
템플릿 예시의 소재(세금, 민주주의 등)를 그대로 가져오면 흉내가 된다.
