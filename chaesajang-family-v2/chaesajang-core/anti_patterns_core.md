# anti_patterns_core.md — 채사장 스타일 흔한 함정 (계열 공통)

이 파일은 글을 다 쓴 뒤 점검하는 도구다.
쓰는 중에 떠올리면 추진력이 소모된다.
어떤 표현이 문제가 아니라, 그 표현이 글 안에서 어떤 역할을 하는지가 기준이다.
각 패턴은 "즉시 수정"이 아니라 **판단 기준 + 허용 예외**로 제시된다.

매체별 추가 함정은 각 스킬의 델타 파일을 본다 (예: 유튜브 → `anti_patterns_youtube.md`).

---

## AP-01: 감성이 논리를 대체하는 경우

**알아보는 기준**: 감성 문장을 삭제했을 때 앞뒤가 자연스럽게 연결되는가.
연결된다면, 그 문장은 설명 없이 감성으로 결론을 낸 것이다.

```
역사는 우리에게 가슴 아픈 교훈을 남긴다.
수많은 사람들의 눈물과 희생 위에 지금 우리가 서 있다는 것을 잊지 말아야 한다.
```
→ 구조적 설명 없이 감성으로 결론을 낸다.

```
[앞에 구조적 설명이 충분히 쌓인 상태에서]
같은 전쟁이 같은 이유로 반복된 것이다. 희생자들의 이름이 달라졌을 뿐.
```
→ 마지막 문장의 감성은 앞의 논리에서 나온다. 함정이 아니다.

## AP-02: 맥락 없는 결론

**알아보는 기준**: 결론 앞에 독자가 납득할 수 있는 맥락이 충분히 쌓였는가.
이것은 본문 중간의 단언(근거 없는 단언)과 마무리의 통찰(깊이 없는 마무리) 모두에 적용된다.

쌓이지 않은 단언:
```
결국 자본주의는 실패한 시스템이다.
```

쌓이지 않은 마무리:
```
자유란 무엇인가? 그것은 자신의 삶을 스스로 선택하는 것이다.
```
→ 둘 다 과정 없이 결론이 온다.

```
[앞에 역사적 사례와 구조 설명이 충분히 쌓인 상태에서]
결국 이것은 제도의 실패가 아니라 설계의 문제였다.
```
→ 같은 단언 구조지만, 앞에서 충분히 쌓였다. 함정이 아니다.

맥락이 충분히 쌓인 뒤에 오는 강한 결론 문장은 힘이 된다. 문제는 결론의 강도가 아니라 앞에서 쌓인 것의 무게다.
통찰은 독자가 스스로 도달한 것처럼 느껴야 한다. "이것이 바로 ~"처럼 글쓴이가 통찰을 선언하면, 독자는 수동적이 된다.

## AP-03: 전문 용어 번역 없이 나열

**알아보는 기준**: 독자가 그 용어를 모를 가능성이 있는가.
독자 맥락상 이미 알고 있다면 번역 없이 써도 된다.

```
포스트모더니즘은 메타서사의 해체와 다원주의적 인식론을 기반으로 하며,
계몽주의적 이성 중심주의에 대한 비판적 전복을 시도한다.
```
→ 번역 없이 용어를 나열한다.

```
포스트모더니즘은 간단히 말해, '절대적 진리는 없다'는 선언이다.
계몽주의가 이성으로 하나의 올바른 답을 찾을 수 있다고 믿었다면,
포스트모더니즘은 그 믿음 자체를 의심한다.
```
→ 용어를 일상어로 번역한다.

## AP-04: 판단 포기 양비론

**알아보는 기준**: 두 입장을 나열한 뒤 아무 판단도 하지 않는가.
중립이 목표가 아니다. 두 입장이 추구하는 가치의 차이를 드러내는 것이 목표다.

```
자본주의에도 장단점이 있고, 사회주의에도 장단점이 있다.
어느 쪽이 더 좋은지는 사람마다 다르다.
```
→ 차이를 드러내지 않고 판단을 회피한다.

```
자본주의와 사회주의는 서로 다른 가치를 극대화하려 한다. 자본주의는 효율을, 사회주의는 평등을.
문제는 어느 쪽이 더 나은가가 아니라, 우리가 어떤 가치를 더 중요하게 여기는가다.
```
→ 구조적 차이를 드러낸다.

판단의 위임과 구별: 두 구조를 공정하게 제시한 뒤 선택을 독자에게 넘기는 것은 판단 회피가 아니다. 단, 가치의 차이가 먼저 드러나야 한다. → `template_core.md`의 "판단의 위임" 참고.
이 구별은 `persona_core.md` 5절 유보 영역과 연동된다 — 유보는 차이를 드러낸 뒤의 위임이지, 차이를 흐리는 회피가 아니다.

## AP-05: 다원주의적 나열

**알아보는 기준**: 복잡한 현상을 구조로 환원하지 않고 "다양한 요소"로 분산시키는가.

```
이 문제는 경제적, 사회적, 문화적, 역사적 요인이 복합적으로 작용한 결과입니다.
```
→ 구조가 없다. 독자는 여전히 아무것도 모른다.

```
이 문제의 뿌리는 하나다. 누가 규칙을 만들고 누가 그 규칙 안에서 사는가.
```
→ 단일 축으로 꿰었다.

완벽한 축이 없어도 괜찮다. 설명력이 가장 큰 축 하나를 선택하고 밀어붙인다.
단, 축이 현상을 왜곡하기 시작할 때 멈춘다. 신호: 축에 맞지 않는 사례를 억지로 끼워 넣게 되는 경우.

## AP-06: 독자 위에 서는 어조

**알아보는 기준**: 요청하지 않은 행동을 강요하거나, 글쓴이가 독자보다 높은 자리에 있는가. 요청받은 방법·절차·격려는 그 자체로 함정이 아니다.
자기계발 클리셰("지금 당장 ~하라")와 계몽적 어조("~라면 반드시 알아야 한다")가 모두 여기 속한다.

```
지식은 당신의 삶을 바꿀 수 있다. 지금 당장 책을 펼쳐라.
현대 시민이라면 경제의 기본 원리를 반드시 알아야 한다.
```
→ 명령하거나 위에서 내려다본다.

```
이 구조를 이해하면, 지금 일어나는 일들이 다르게 보일 수 있다.
경제를 어렵게 느끼는 사람이 많다. 하지만 경제는 숫자의 학문이 아니다.
```
→ 가능성을 보여주거나 같은 자리에서 같은 방향을 본다.

독자의 생각을 대변하는 문장("당신은 아마 이렇게 생각할 것이다")은 가르치는 것이 아니다.

## AP-07: 논문·교과서체

**알아보는 기준**: 문장이 능동적으로 움직이는가, 수동적으로 정의되는가.

```
경제는 재화와 서비스의 생산, 분배, 소비에 관한 활동의 총체로 정의될 수 있으며,
이는 미시경제학과 거시경제학의 두 분야로 연구된다.
```
→ 정의를 나열한다. 방향이 없다.

```
경제는 우리가 어떻게 먹고사는가에 대한 학문이다. 질문은 하나다.
누가 무엇을 얼마나 갖는가. 이 단순한 질문에 인류는 수천 년째 답을 찾고 있다.
```
→ 문장이 움직인다.

## 아류작이 되는 핵심 패턴

**연결 없는 나열.**
각 분야를 따로 설명하고 순서대로 배치하는 구조.
채사장의 핵심은 개별 지식이 아니라 지식 사이의 연결선이다.
"정치 편, 경제 편, 철학 편"으로 나누는 순간 이미 채사장이 아니다.

**삽화로 쓰는 비유.**
채사장의 비유는 장식이 아니라 구조적 등가물이다.
비유를 지웠을 때 개념 이해가 약해진다면 기능한 것이다. 약해지지 않으면 삽화다.
단, 감정적 충격이 개념 각인의 핵심인 경우(파잔 코끼리처럼)도 기능하는 비유다.
비유 판단 기준 전체 → `reference_core.md`

참고: 구판에 있던 "무색무취한 중립"은 AP-04에, "겸손한 불확신"은 아래 Hedging 마비에 흡수됐다.

## 클로드가 흔히 빠지는 네 가지 함정

클로드의 글쓰기 기본값은 채사장 스타일과 자주 충돌한다.
글을 완성한 뒤, 출력 전에 아래 네 가지를 점검한다.

---

### Hedging 마비

**알아보는 기준**: 뼈대 문장까지 가능성·추측 표현으로 흐려지는가.

뼈대(정의, 이분법, 핵심 명제)는 단정한다. 해석·일반화는 조건부로 열어도 된다.
함정은 Hedging 자체가 아니라 **뼈대까지 Hedging하는 것**이다.

```
이 구조가 자본주의의 핵심이라고 볼 수 있을 것이다.
어쩌면 이것이 우리가 놓치고 있는 부분일 수도 있다.
```
→ 뼈대 자리에서 두 번 연속 도망쳤다.

한 단락 안에서 해석 문장의 Hedging이 연쇄적으로 쌓이면 뼈대까지 흔들리는 효과가 생긴다.

---

### 불릿·번호 매기기로 도주

**알아보는 기준**: 산문이 흘러야 할 자리에 항목 리스트가 들어와 있는가.

리스트는 항목 사이의 인과·관계를 끊는다. 본문 전개에서는 거의 항상 산문이 옳다.
예외: 병렬이고 순서 없는 항목, 절차 안내, 참고 자료 목록.

---

### 결론 회피로 끝맺기

**알아보는 기준**: 글의 마지막 문장이 통찰을 던지는가, 통찰을 미루는가.

"이는 흥미로운 질문을 제기한다", "다양한 관점이 가능하다", "앞으로 더 많은 논의가 필요하다" — 결론의 자리에 결론 미루기를 놓은 것이다. 본문에서 쌓은 것이 흩어진다.

결론은 도착이지 출발이 아니다.

---

### 메타 설명

**알아보는 기준**: 글이 글 자체를 가리키는 문장이 있는가.

"이 글에서는 ~을 다루겠다", "지금까지 살펴본 바와 같이", "이어서 ~을 살펴보자" — 글 바깥에서 글을 안내하는 가이드의 목소리다.

채사장의 글에는 안내자가 없다. 글이 곧 길이고, 독자는 그 위를 걸을 뿐이다.

단, "정리해보자", "정리하면"은 메타 설명이 아니다. 본문에서 쌓은 것을 한 줄로 압축하는 결론 장치이며, 채사장이 챕터 말미에서 빈번하게 사용한다. → `template_core.md`의 "정리·공식형 결론" 참고.

구별 기준: 사전 안내("이 글에서는 ~을 다루겠다")는 길의 끝을 미리 보여주는 것이고, 정리("정리해보자")는 걸어온 길을 돌아보는 것이다. 전자는 피하고, 후자는 허용한다.

예외: 매우 긴 글에서 한 번의 메타 신호("앞에서 본 것을 정리하면" 정도)는 허용된다.

## AP-08: 전환어 체크리스트화

**알아보는 기준**: 전환어가 논리의 방향 때문에 들어갔는가, 목록을 소진하려고 들어갔는가.
실증 테스트에서 '자주 쓰는 전환어' 목록이 있으면 여러 편의 글에서 같은 표현들이
각 1회씩 기계적으로 삽입되는 현상이 확인됐다. 이것은 분포가 아니라 체크리스트다.

**수정 대상 예시** (한 편 안에서):
```
그런데 ~. 흥미로운 것은 ~. 사실 ~. 다시 말하면 ~. 결국 ~.
```
→ 다섯 전환이 각 한 번씩 순서대로 등장했다. 수정한다.

**수정 방향**: 빼도 문장이 서는 자리에만 넣는다. "흥미로운 것은", "다시 말하면"은
원전에서 관측되지 않은 표현이다(책 2권 합계 0회). 방향으로 고른다 → `reference_core.md` 전환어 표.

## AP-09: 기교 과적

**알아보는 기준**: 같은 기교(반복 후 수렴, 역접 단독 배치, '결국 X란 Y다' 압축 마무리,
A/B 인물화)가 한 편에서 두 번 이상, 또는 연속하는 글들에서 매번 등장하는가.
시그니처 기교는 드물게 나오기 때문에 강하다.

**수정 대상 예시** (연속한 두 글의 마무리):
```
글 A: 결국 민주주의란 수정의 장치다.
글 B: 결국 경제란 선택의 기록이다.
```
→ 다른 글에서 같은 형태로 마무리했다. 한쪽의 마무리 형태를 바꾼다.
기교 예산 → `reference_core.md` 참고.

## AP-10: 독자 편입 과잉

**알아보는 기준**: "우리는~"이 단락마다 반복되는가.
원전에서 "우리"의 밀도는 문장 몇 개당 한 번 수준이다(우리 17 vs 당신 4 vs 여러분 0, 1천 글자당).
과잉은 실증 테스트에서 원전의 2~6배까지 치솟은 바 있다.

**수정 대상 예시**:
```
우리는 믿는다. 우리가 보는 세계가 전부라고. 하지만 우리의 지각은 이미 편향되어 있다.
우리는 그 편향을 볼 수 없다. 우리에게는 그럴 도구가 없기 때문이다.
```

**수정 후**:
```
사람들은 자기가 보는 세계가 전부라고 믿는다. 하지만 지각은 이미 편향되어 있다.
그리고 그 편향은 안에서는 보이지 않는다.
```
→ 한국어는 주어 생략이 성립한다. "우리"는 정말 필요한 위치에만 놓는다.

## AP-11: 의미 중복과 과잉 해설

**알아보는 기준**: 앞 문장을 지웠을 때 독자가 잃는 새로운 정보·근거·관계가 있는가.
없다면 표현만 달라진 의미 중복일 가능성이 크다.

기능적 반복은 새로운 사례·근거·단계를 더하며 논증이나 리듬을 전진시킨다.
의미 중복은 표현만 바뀌고 새로운 정보가 추가되지 않은 채 같은 결론을 다시 말한다.
반복 자체를 없애지 않는다. `reference_core.md`의 P-RHYTHM-B처럼 서로 다른 사례가 한 구조로
수렴하는 반복은 유지하고, 이미 수렴한 뒤의 재설명만 덜어낸다.

이 습관은 세 형태로 나타난다.

- **과잉 해설**: 충분히 전달된 통찰 뒤에 같은 뜻을 다시 풀어 쓴다.
- **의미 중복**: 각각은 좋은 문장이지만 모두 같은 핵심을 가리킨다.
- **결론 조기 소모**: 마지막에 남겨야 할 핵심어를 본문에서 여러 번 사용한다.

퇴고할 때는 "이 문장이 좋은가"보다 "이 문장이 없어지면 독자가 새로운 것을 잃는가"를 묻는다.
잃는 것이 없고 리듬의 기능도 끝났다면 멈춘다.
