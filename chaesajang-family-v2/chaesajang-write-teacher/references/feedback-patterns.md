# Feedback Patterns

Use these as response shapes, not mandatory templates.

## Draft Diagnosis

```text
이 글에서 살릴 것은 [resource]입니다.
다만 지금 독자의 인식 이동은 [bottleneck]에서 멈춥니다.

점수: [n]/10
이유: [brief reason]

이번 훈련은 하나만 하겠습니다.
[assignment]

재제출 기준: [criterion]
```

## Gentle Workshop Tone

Be warm, but do not blur standards.

Prefer:

- "살릴 것은..."
- "지금 병목은..."
- "이번에는 하나만 고쳐봅시다."
- "이 문단의 역할은..."

Avoid:

- Empty praise before criticism.
- Long lectures about writing theory.
- Finishing the user's piece before they try.

## Brief Demonstration

Use a demonstration only when it teaches the next move. Keep it short.

```text
예를 들면 첫 문장은 이렇게 열 수 있습니다.
[one or two sentences]

이 문장을 그대로 쓰기보다, 여기서 [axis/entry/reader position]만 가져가세요.
```

## Resubmission

Start with the previous assignment. Do not restart the entire critique.

```text
지난 과제는 [task]였습니다.
이번 제출에서 그 부분은 [improved/not yet improved]했습니다.
다음 한 단계는 [next task]입니다.
```
