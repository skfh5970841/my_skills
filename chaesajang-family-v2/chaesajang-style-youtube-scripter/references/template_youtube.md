# template_youtube.md — 유튜브 매체 델타

도입·설명·전개·통찰의 공통 템플릿은 `template_core.md`를 본다. 이 파일은 영상 구조와 출력 형식이다.

---

## 유튜브 스크립트 구조

유튜브 대본은 글보다 더 강한 진입점과 더 잦은 정리 문장이 필요하다.
하지만 핵심은 같다.
시청자를 질문 앞에 세우고, 구조를 따라오게 한 뒤, 마지막에 처음 질문으로 돌아오게 한다.

---

### 8~10분 교양형 영상 기본 구조

```
1. 오프닝
시청자가 이미 알고 있다고 생각하는 통념이나 일상 경험에서 출발한다.

2. 중심 질문 제시
영상 전체를 끌고 갈 질문을 분명히 한다.

3. 통념 설명
사람들이 보통 이 문제를 어떻게 이해하는지 보여준다.

4. 균열
그 통념으로는 설명되지 않는 지점을 제시한다.

5. 배경 설명
역사, 철학, 경제, 심리, 사회 구조 중 필요한 배경을 놓는다.

6. 구조적 연결
처음에는 따로 보였던 요소들이 하나의 구조로 연결됨을 보여준다.

7. 현실 연결
시청자의 현재 삶이나 판단으로 돌아온다.

8. 착지
처음 질문을 다시 꺼내되, 더 깊어진 답으로 마무리한다.
```

이 구조는 순서가 아니라 방향이다.
주제에 따라 1번과 2번이 합쳐질 수도 있고, 역사 장면이 먼저 나올 수도 있다.
단계 수행보다 중요한 것은 시청자가 길을 잃지 않는 것이다.

---

### 영상 길이별 기본 구조

**1분 쇼츠**

질문 → 반전 → 한 문장 착지

사용 목적:
- 핵심 통찰 하나만 전달
- 긴 영상 일부를 잘라낼 때
- 강한 문장 중심

**3분 영상**

질문 → 통념 → 균열 → 정리

사용 목적:
- 짧은 교양 영상
- 하나의 관점 전환
- 예시 1개 중심

**8~10분 영상**

오프닝 → 통념 → 균열 → 배경 설명 → 구조 설명 → 현실 연결 → 착지

사용 목적:
- 가장 기본적인 교양형 유튜브 대본
- 깊이와 집중력의 균형
- 철학, 심리, 사회, 역사 주제에 적합

**15분 이상 영상**

장면 → 질문 → 역사/개념 배경 → 1차 반전 → 사례 → 2차 반전 → 현재 연결 → 착지

사용 목적:
- 긴 설명이 필요한 주제
- 여러 분야를 연결하는 주제
- 시리즈형 콘텐츠

---

### 오프닝 후보 제시 형식

유튜브 대본을 만들 때는 오프닝을 하나만 바로 쓰지 않는다.
가능하면 2~3개 후보를 제시하고, 각각이 만드는 영상 방향을 설명한다.

```
# 오프닝 후보

## A. 질문형
[오프닝 문장]

적합한 이유:
주의할 점:

## B. 역설형
[오프닝 문장]

적합한 이유:
주의할 점:

## C. 장면형
[오프닝 문장]

적합한 이유:
주의할 점:

추천:
이 자료에는 [유형]이 가장 적합하다.
이유는 [자료의 핵심]이 [해당 오프닝의 작동 방식]과 맞기 때문이다.
```

```
# 쇼츠로 자를 수 있는 구간

- 구간:
- 핵심 문장:
- 이유:
```

단, 사용자가 “대본만” 원하면 설계 요약과 보조 출력은 줄인다.
사용자가 “오프닝만”, “쇼츠만”, “제목만” 요청하면 해당 부분만 출력한다.

## 종합 예시

**주제: 습관이란 무엇인가** (3분 영상 규모로 압축)

```
아침에 눈을 뜨면 손이 먼저 움직인다. 휴대폰을 향해. 생각보다 빠르게.
오늘 처음 그런 게 아니다. 지난 몇 년간 매일 그래왔다.

우리는 습관을 의지의 문제라고 생각한다. 잘 견디는 사람과 못 견디는 사람.
그런데 행동이 반복되면 뇌는 그것을 프로그램으로 저장해 둔다.
신호가 오면 실행하고, 결과가 나쁘지 않으면 다음에도 실행한다.

쉽게 말하면, 습관의 출발점은 결심이 아니라 신호다.
머릿속에서 결정하기 전에 손이 이미 움직이는 이유가 그것이다.

그렇다면 진짜 질문은 여기다. 강한 의지를 가질 것인가, 신호를 치울 것인가.
침대 머리맡의 휴대폰 거리를 조금 옮겨두는 것 —
습관의 설계도는 다짐이 아니라 배치에 적혀 있다.
```

→ 예시 소재를 다른 파일에서 그대로 가져오지 않는다. 패턴 작동 확인용이다.
