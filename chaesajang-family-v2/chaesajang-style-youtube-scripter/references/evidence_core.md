# evidence_core.md — 견해와 운영 규칙의 근거

2026-09-13 검토. 이 문서는 작가의 고유 문체를 생성하는 지침이 아니라 사실 귀속을 점검하는 자료 기록이다. 원문 자막은 재배포하지 않는다.

## 판정 범위

‘자료 확인’은 사용자가 제공한 자막에서 해당 발언을 읽었다는 의미다. 원영상 URL과 타임스탬프는 제공되지 않았으며, 오인식과 화자 표지 누락 때문에 음성 대조를 마친 인용으로 취급하지 않는다. S2의 질문자 발언은 저자의 주장에 포함하지 않는다.

범위는 원본 UTF-8 문자열의 1부터 시작하는 문자 번호이며 끝을 포함한다. Python `text[a-1:b]`에 해당한다. 공백과 HTML 엔터티를 그대로 센다. 원본이 변경되면 해시와 위치를 다시 확인한다. 원문이 없으면 아래 기록의 한계를 밝히고 직접 확인했다고 주장하지 않는다.

## 핵심 판단

| 독서나 철학적 탐구를 강요하지 않는 태도 | 자료 확인, S2·S3 | 요청하지 않은 훈계를 제한한다. |
| 요청받은 실용적 제안 허용 | 운영 선택 | 앞 태도와 구분하며 작가의 직접 선언이라고 쓰지 않는다. |
| 작가가 무신론자라는 규정 | 미확인 | 이번 자료로 소속·정체성을 확정하지 않는다. |
| 죽음 인식이 모든 사유의 필수 조건 | 미확인 일반화 | 가능한 계기 중 하나로 한정한다. |
| 기존 기원 서사의 사건 순서·인과와 지적 계보 | 미확인/해석 | 개별 출처 없이 전기적 사실로 사용하지 않는다. |
| 결론·정의 위치를 요청에 맞춰 선택 | 운영 선택 | 매체의 일반적 구성 관행보다 명시된 요청을 우선한다. |
