## 3. 실패 유형 확정 (5가지)

**F1. 전환어 체크리스트화**
SKILL.md의 "자주 쓰는 전환어" 5종 목록이 분포가 아니라 체크리스트로 소비됨. 8개 출력 모두 5종을 각 1회씩 소진하는 체커보드 패턴.
→ 딥리서치 2의 경고 그대로: "구체적 특징 나열은 분포 학습이 아니라 체크리스트 실행을 낳는다".
→ 근거 수정 필요: 목록 삭제 or 빈도 정보 없는 "관찰된 선택지"로 강등 + 실측 상위(하지만/그리고/우선/그래서/다만)로 교체.

**F2. 리듬의 단극화**
단문 연속 지침이 과잉 적용되어 평균 20~26자로 수렴. 원전의 핵심은 "짧게 전제→길게 확장→짧게 판정"의 3박자인데 출력은 '짧게'만 남음.
→ 지침에 3박자 공식과 길이 가이드(중위값 30자 안팎, 확장문 허용) 명시 필요.

**F3. 시그니처 기교의 매출 반복**
'반복→수렴', '결국 X란 Y다' 압축 마무리가 8개 전부 동일 위치·동일 형태로 출현. Verbalized Sampling이 지적한 mode collapse.
→ 기교 예산(device budget) 조항 필요: 동일 기교 연속 글 사용 금지, 글당 수렴 장치 0~1회 등.

**F4. 독자 편입 과잉 교정**
'우리' 사용이 원전의 2~6배. x2는 10문장에 '우리' 9회.
→ "우리>당신>여러분 순서이나 원전 밀도는 17/10k 수준"이라는 앵커 제공 필요.

**F5. 예시 소재 복사**
t1이 template.md 세금 예시의 골격(권력의 언어→시민의 언어)을 거의 재생산. 예시가 few-shot이 아니라 복사원이 됨.
→ 예시를 원전 발췌(짧은 인용)로 교체하고 "예시 소재 재사용 금지" 조항 추가.

## 4. 유지 확인된 강점
- 변환 판단(x1/x2): 원본 강점 보존·정의서술 해체·감성→구조 치환이 지침대로 잘 작동 ✅
- 한다체 단정 어조, 이분 축 구조화, 도입의 통념 제시 ✅
- SKILL.md의 "규칙이 아니라 판단 방식" 프레임은 agentskills best-practice("왜를 설명하라")와 부합 — 철학 파트는 유지
