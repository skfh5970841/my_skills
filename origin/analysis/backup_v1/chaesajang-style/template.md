# template.md — 채사장 스타일 글쓰기 템플릿

각 템플릿은 공식이 아니라 **작동 원리 + 다양한 예시**다.
예시를 복사하지 말고, 원리를 이해해서 주제에 맞게 변형한다.
예시의 소재(세금, 민주주의 등)를 그대로 가져오면 흉내가 된다.

---

## 도입 템플릿

채사장의 도입은 독자를 "이미 살고 있는 문제" 앞에 세운다.
원전 실측에서 첫 문장이 물음표로 시작하는 경우는 없었다.
질문은 도입의 형식이 아니라 **논증을 움직이는 장치**다. 도입에서 질문은 '소환'할 뿐이다.

### T-INTRO-A: 통념 인정 후 간극형

**작동 원리**:
독자가 당연하게 여기는 통념을 먼저 인정한 뒤, 그 안의 균열을 보여준다.
반전이 강할수록 좋다. 단, 뒤집을 통념이 독자 대부분이 실제로 믿는 것이어야 한다.

**적용 조건**: 글의 핵심이 기존 인식의 전복일 때.

**예시 A**:
```
경제를 배우면 돈에 대한 환상이 사라진다고들 한다.
그런데 정작 경제학자들은 돈이 무엇인지에 대해 만 명이면 만 가지 대답을 내놓는다.
환상이 사라진 자리에 남는 건 지식이 아니라 더 큰 물음이다.
```

**예시 B**:
```
자유는 좋은 것이다. 누구나 원한다.
문제는 자유가 하나가 아니라는 것이다.
어떤 자유는 다른 사람의 자유를 빼앗는 방식으로만 실현된다.
```

→ 두 예시 모두 물음표가 없다. 질문은 평서문 속에 소환되어 있다.

### T-INTRO-B: 구체 장면형

**작동 원리**:
구체적인 장면 — 역사든 일상이든 — 으로 바로 들어간다.
첫 문장이 평서문이어도 괜찮다. 장면 자체가 진입점이다.
현재와 연결된다는 암시를 마지막에 둔다. 연결을 직접 설명하지 않는다.

**적용 조건**: 주제를 가장 잘 보여주는 순간이 존재할 때.

**예시 A** (역사 장면 — 원전 발췌, 『시민의 교양』 서두):
```
티벳에는 죽은 사람들을 위한 안내서가 있다. 죽은 다음에 개인이 겪게 될 일들에
대해서 차근차근 설명해주는 것이다. 죽은 사람을 위한 안내서도 있는데,
산 사람에 대한 것도 있어야 하지 않겠냐 하는 마음에 이 책을 쓰기 시작했다고
저자는 밝힌다. 살아 있는 사람들을 위한 안내서.
```

**예시 B** (일상 장면):
```
아침마다 같은 버스를 탄다. 같은 문으로 들어가서, 같은 자리에 앉는다.
문득 그렇게 몇 년이 흘렀다는 걸 뒤늦게 깨닫는다.
습관이라는 건 언제나 이렇게 — 계산이 끝난 다음에야 발견된다.
```

### T-INTRO-C: 정의의 번역형

**작동 원리**:
낯선 개념을 다룰 때, 정의를 먼저 내놓지 않는다.
독자가 이미 겪고 있는 현실에서 시작해, 그것이 곧 개념임을 뒤늦게 드러낸다.
전문 용어 지연 도입(reference.md 참고)과 결합하면 가장 강력하다.

**적용 조건**: 개념 설명이 곧 글의 본문일 때.

**예시 A**:
```
월급날이 기다려지는데 월급이 다 쓰고 나면 남는 게 없는 상태.
그 상태가 개인이 아니라 나라 전체에 벌어졌을 때, 경제학자들은 특별한 이름을 붙였다.
```

## 개념 설명: 추상에서 구체로

기본 방향은 추상 → 구체 → 비유 → 한 문장 정리다.
비유는 개념을 더 명확하게 만들 때만 추가한다. 비유가 목적이 아니다.

```
잉여 가치란 노동자가 만들어낸 가치 중 임금으로 돌아오지 않는 부분이다.
하루에 100만 원어치 제품을 만드는 노동자가 30만 원을 받는다면,
나머지 70만 원은 자본가에게 귀속된다.
마르크스는 이 구조가 우연한 결함이 아니라 작동 원리 자체라고 봤다.
결국 잉여 가치는 자본주의가 유지되는 연료다.
```

독자가 이미 개념을 어느 정도 알고 있다면, 아는 설명을 먼저 인정하고 더 깊이 들어간다.

```
자유란 하고 싶은 것을 할 수 있는 상태라고 흔히 말한다.
사실 이것은 자유의 절반만 담은 설명이다.
더 정확하게 말하면, 자유는 하기 싫은 것을 거부할 수 있는 상태다.
이 차이는 우리가 어떤 사회 제도를 설계하느냐에서 결정적으로 드러난다.
```

## 전개: 논증 중간의 질문 연쇄

원전에서 질문은 도입이 아니라 **전개의 점프대**로 쓰인다.
정의나 장면을 제시한 뒤, 짧은 질문을 연달아 던져 독자를 한 단계씩 옮긴다.
물음표 형태("~인가", "~는가")도, 물음표 없는 의문형("~일까", "~는지")도 쓰인다.

```
국가는 어디서 왔는가. 왜 사람들은 스스로에게 규칙을 묶어 두었는가.
안전 때문일까. 그렇다면 왜 그 규칙은 안전과 무관한 곳까지 손을 뻗는가.
```

판단 기준:
- 질문 연쇄는 2~3개가 한 묶음이다 (원전 관측값)
- 답을 아는 질문(수사 의문)과 진짜 열린 질문을 섞는다
- 한 단락 전체를 질문으로만 채우지 않는다

## 전개: 예상치 못한 연결

하나의 개념을 설명한 뒤, 전혀 다른 분야와의 연결로 독자가 예상하지 못한 시야를 만든다.
연결은 억지로 만들지 않는다. 실제로 구조가 같을 때만 연결한다.

```
면역 체계는 침입자를 기억한다. 다음에 오면 더 빨리 제압하도록.
법 체계도 같은 일을 한다. 판례란 사회의 항체다.
다만 면역과 법이 다른 점 하나 — 법은 새로운 병에 대한 항체를 만드는 데 수십 년이 걸린다.
```

같은 구조의 문장을 반복할 때, 반복 횟수는 리듬이 완성되는 지점에서 결정한다.
2회로 충분하다면 굳이 3회를 채우지 않는다.

## 통찰: 어떻게 마무리할 것인가

마무리의 방향은 세 가지다. 한 편에는 하나만 쓴다.

**도입 귀환**: 처음 제시했던 장면·통념을 다시 꺼내, 본문에서 쌓은 맥락으로 다른 의미를 입힌다.
```
처음의 버스로 돌아가 보자. 같은 버스, 같은 자리.
바뀐 것은 없다. 바뀐 것은 그 자리에 앉아 있는 방식이 선택이었다는 사실을 아는 것.
```

**인식 역전**: 독자가 갖고 있던 인식을 명시적으로 뒤집는다.
```
우리는 경제를 숫자의 학문이라고 생각해왔다.
그런데 경제는 인간의 욕망과 공포가 만들어내는 이야기다.
```

**확장 후 착지**: 개인 → 사회 → 역사로 넓혔다가, 마지막 문장을 독자의 현재로 돌린다.

셋 중 무엇을 고르든, 글쓴이가 통찰을 선언하지 않는다.
"결국 X란 Y다" 형태의 압축 마무리는 강력하지만, 연속한 글에서 반복하면 버릇이 된다.
독자가 스스로 도달한 것처럼 느껴야 한다.

## 종합 예시

**주제: 습관이란 무엇인가**

사용 패턴: T-INTRO-B(일상 장면) → 개념 설명(용어 지연 도입) → 질문 연쇄 → 확장 후 착지

```
아침에 눈을 뜨면 손이 먼저 움직인다. 휴대폰을 향해. 생각보다 빠르게.
그 손은 오늘 처음 그런 게 아니다. 지난 몇 년간 매일 그래왔다.

행동이 반복되면 뇌는 그것을 목록에 저장한다. 매번 새로 결정하는 게 아니라
저장된 프로그램을 실행하는 것. 이를 어려운 말로 '습관화'라고 부른다.
신호가 오면 행동이 따라오고, 결과가 좋으면 회로가 굳는다.

그런데 여기서 이상한 질문 하나가 나온다. 그 손을 움직인 것은 나인가, 회로인가.
의지는 매번 새로 소모된다. 회로는 한 번 굳으면 저절로 돈다.
이길 수 없는 싸움이라면, 이기려 하지 말고 다른 질문을 해야 한다.

회로를 만드는 입력은 무엇이었나. 침대 머리맡에 둔 휴대폰. 현관에 없던 운동화.
습관의 설계도는 다짐이 아니라 배치에 적혀 있다.
오늘 아침 손이 뻗어간 그 거리를 조금 옮겨두는 것부터가 설계의 시작이다.
```
