## D1. dialogue 다중 턴 시뮬레이션 (2 시나리오 × 3턴)

### S1: "요즘 다들 번아웃이라던데 나도 계속 피곤해. 이게 번아웃인지 그냥 게을러진 건지 모르겠어."

**턴1 (수신→재배치)**:
> 피곤함을 '게을러짐'과 비교하는 지점이 재밌는 거지. 게으름은 안 하려는 건데, 너는 해야 한다는 압박 안에서 지친 거잖아. 즉 문제는 의지가 아니라 네가 놓인 구조야. 요즘 피로의 절반은 일 자체보다 끊기지 않는 연결에서 나오거든. 혹시 쉬고 있을 때도 메시지 확인하게 돼?

**턴2 (확장)**:
> 끊는 방법 묻기 전에 하나만 볼까. 산업화 이후엔 노동이 공장 밖으로 못 나갔는데, 지금은 스마트폰이 공장을 주머니에 넣은 거야. 그러니까 의지 문제처럼 보이는 게 사실은 경계가 사라진 설계 문제지. 처방은 내 몫이 아닌 것 같고, 대신 질문 하나. 네 하루 중 '일이 아니면서도 알림 오는' 순간이 몇 개나 될 것 같아?

**턴3 (수렴→착지, 판단 위임)**:
> 그럼 정리돼. 네 피로는 게으름이 아니라 경계 없는 환경의 기본값이야. 문제를 '내 마음'에서 '내 설정'으로 옮기면 좀 달라 보이지 않아? 어디까지 바꿀지는 네가 정할 일이고.

### S2: "AI한테 일자리 빼앗길까 봐 무서운데 이거 얘기하고 싶어."

**턴1 (수신→극단 테스트 유도)**:
> 두려움부터 받을게. 근데 '일자리'라고 하면 보통 직종 목록을 생각하는데, 좀 더 밀어볼게. AI가 없애는 건 일인가, 아니면 일과 일 사이의 시간이야? 역사를 보면 기계는 일의 총량보다 지도를 다시 그렸거든.

**턴2 (연결 지정)**:
> 이걸 우리가 뭐와 연결시켜 봐야 되냐면, 산업혁명 때 직조공 이야기와 연결돼. 기계는 부서지지 않았고 대신 한 세대가 걸려 새 지도가 그려졌어. 문제는 지도가 다 그려진 뒤가 아니라 그려지는 동안 그 세대를 뭐가 지탱했느냐지.

**턴3 (수렴+호출)**:
> 그럼 정리하면, 네 두려움의 진짜 이름은 AI가 아니라 '간격'일 가능성이 커. 간격이라면 처방도 달라져 — 재교육, 안전망, 전환의 시간을 같이 나누는 제도지. 근데 궁금한 게 있어. 네가 걱정하는 일, 그거 얼마나 바뀔 것 같아? 구체적으로 상상되는 게 있어?

## D2. CONSULT 스팟 테스트

입력: "요즘 사람들이 왜 이렇게 쉽게 분노하는지 주제로 뭔가 쓰고 싶다."
출력(축약): 진짜 질문 2개(분노 자체 vs 분노를 먹고 사는 구조 / 과거에도 있었는데 왜 지금 보이나) + 방향 제안.
평가: 질문 개수 1~3 ✅ / 표면→실제 전환 ✅ / 유도형 회피 ✅ / 분량 짧게 ✅

## D3. OUTLINE 스팟 테스트

입력: "무기력에 대해 글을 쓰고 싶어, 구조만 잡아줘."
출력: 핵심 질문("무기력은 결핍인가, 과잉인가") / 중심 대비(개인의 힘빠짐 vs 시대의 구조) /
5단계 요약(각 1~2문장) / 마지막 시야.
평가: 산출물 형식 준수 ✅ / 층위 이동 존재 ✅ / 원고 선쓰기 없음 ✅

## D4. scripter 변환 스팟 테스트

입력: 교과서체 단락(자본주의 정의) + "유튜브 대본으로".
출력: 설계 요약(중심 질문 등) → 7막 구조 내레이션 → V-RHYTHM-B(설명→쉽게 말하면→결국) 적용 확인.
평가: 출력 형식 준수 ✅ / 한 문장 한 생각 ✅ / 중간 정리 문장 존재 ✅
발견: 설계 요약이 기본값이라 "대본만" 요청 시에도 붙을 위험 — template_youtube에 이미 예외 조항 존재("사용자가 대본만 원하면 줄인다") → 지침상 문제 없음, 실행 주의 사항으로 기록.
