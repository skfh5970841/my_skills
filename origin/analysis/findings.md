## 1. 핵심 발견 (요약)

### 1-1. 원전 실측이 반박한 스킬의 사양 (치명도 순)
1. **전환어 목록 오류**: "흥미로운 것은"(책 2권 합계 **0회**), "다시 말하면"(**0회**)이 스킬에는 '자주 쓰는 전환어'로 기재. 실제 상위: 하지만·그리고·우선·그래서·다만·즉. "그런데=핵심 전환어"는 과장(중빈도 3.5/10k).
2. **도입 이론 불일치**: 공개 발췌 17블록 중 첫 문장 질문 **0개**. 질문은 논증 중간 연쇄(인가/는가형 5~9/10k)로 사용됨. 도입의 실제 진입은 장면·정의 제시·통념 인정.
3. **누락된 시그니처 — 가상 대화·인용 장치**: 지대넓얕 1 문장의 **12.7%**가 인용부호 포함. A/B 인물화 패턴이 대표 장치인데 style 스킬에는 없음(advisor에만 있음).

### 1-2. 실증 테스트가 재현한 실패 (현재 지침대로 쓰면)
- F1 전환어 5종이 8개 출력 모두 '각 1회' 체크리스트 삽입 ← 목록 나열의 직접 결과
- F2 문장 과단편화(평균 20~26자 vs 원전 34~38자)
- F3 '결국 X란 Y다' 마무리 등 시그니처 기교 매출 반복(mode collapse)
- F4 '우리' 과잉(원전의 2~6배)
- F5 예시 소재 복사(t1이 template 세금 예시 재생산)

### 1-3. 검증된 강점 (유지)
철학 레이어("규칙이 아니라 판단 방식", 감성은 논리의 결과, 통찰 선언 금지)는 저자 인터뷰·원전과 부합. 변환 판단 절차도 잘 작동.

## 2. 파일별 수정안 (우선순위)

### P0 — SKILL.md
1. 전환어 단락 재작성: 5종 목록 삭제 → 실측 상위 전환어를 "관찰 빈도" 정보와 함께 제시하되, **선택은 논리 방향에 따라**라는 판단 원리로 서술. "흥미로운 것은/다시 말하면"은 예시에서도 제거.
2. 리듬 단락에 3박자 공식 명시: "짧게 전제 → 길게 확장 → 짧게 판정. 확장문을 피하지 말 것(원전 평균 ~30자)."
3. 신규 섹션 "가상 대화·인용 장치": 추상 구조를 두 인물의 구어체 대화로 치환 → 직후 1문장 해석. (advisor reference.md의 P-STRUCTURE-C 흡수, 실측 12.7%가 근거)
4. 독자 편입 앵커 추가: "'우리'가 기본 위치. 당신은 간헐적. 여러분은 거의 안 씀. 원전 밀도 ≈ 우리 17회/1천문장 수준 — 과잉 주입 금지."
5. **기교 예산(device budget)** 조항 신규: 동일 기교(반복→수렴, 역접 단독, 결국 압축 마무리)는 한 글에서 최대 1~2회. 연속 생성 간 재사용 금지. (Verbalized Sampling 근거)
6. 파일 로딩 조건 명시화(specification 권고): "~참고"를 "언제 읽는지" 문장으로 교체.
7. 예시 교체 지침: "템플릿 예시의 소재(세금 등)를 그대로 쓰지 않는다."

### P1 — reference.md
- 전환어 테이블을 실측 데이터로 교체 (하지만/그리고/우선/그래서/다만/즉 + 그런데는 보조 역할로 하향)
- P-RHYTHM-C를 "역접 계열(하지만·다만)"으로 확장, 그런데 단독 배치는 옵션으로 강등
- 예시 A/B/C 일부를 원전 발췌(짧은 인용, 출처 병기)로 교체해 다양성 확보

### P1 — template.md
- 도입 유형 재정렬: ①통념 인정 후 간극 ②구체 장면(역사·일상) ③정의의 번역형 — 질문형은 '질문을 소환하는 평서문'으로 재정의하고 논증 중간 질문 연쇄 패턴 신설
- 종합 예시 교체(세금 소재 탈피)

### P2 — transformation_rules.md / anti_patterns.md
- **advisor판으로 통합**(RULE-XX/AP-XX 라벨, 수정 후 before-after 예시 — TICL의 contrastive explanation 근거)
- anti_patterns에 F1~F5 실패 사례(이번 테스트 출력)를 anti-example로 추가 가능

### P2 — description (트리거)
- 현재 description은 기능 나열 위주. optimizing-descriptions 가이드대로 "사용 의도+맥락" 중심으로 재작성:
  예) "채사장(지대넓얕)의 문체로 글을 쓰거나 변환할 때 사용. '쉽고 깊게', '교양 글쓰기', '지적인 에세이'처럼 문체 요청이 암시된 경우에도 발동."

### P3 — 경계 재설계 (두 스킬)
- 문체 레퍼런스 4종의 **single source of truth**: `chaesajang-style/`을 원본으로, advisor/references의 4종은 삭제 후 SKILL.md 로딩 경로를 style 스킬로 연결 (또는 `_shared/` 디렉토리)
- 역할 선긋기 유지: style = 문장 엔진 / advisor = 모드 워크플로우(CONSULT·OUTLINE·WRITE)
- advisor mode_write.md 2.4의 전환어 예시도 실측 반영으로 함께 수정
